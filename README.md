# Banking Information System
**Upskill Campus — Core Java Internship Project**

## Project Overview
A console-based Banking Information System prototype built in Core Java demonstrating key banking functionalities.

## Features
- User Registration with unique account number generation
- Secure Login with password authentication
- Deposit & Withdrawal with balance tracking
- Fund Transfer between registered accounts
- Account Statement with full transaction history
- Account Management (view & update details)
- Error handling for insufficient funds, invalid inputs

## How to Compile and Run

### Prerequisites
- Java JDK 11 or higher

### Compile
```bash
javac BankingInformationSystem.java
```

### Run
```bash
java BankingInformationSystem
```

## Sample Usage
```
[1] Register New Account   → Create an account
[2] Login                  → Access your dashboard
[3] Exit
```
After login:
```
[1] View Account Details
[2] Update Account Info
[3] Deposit
[4] Withdraw
[5] Fund Transfer
[6] Account Statement
[7] Logout
```

## Technologies Used
- Core Java (JDK 11+)
- Java Collections (HashMap, ArrayList)
- Java Scanner for user input
- Java Date/Time for transaction timestamps
